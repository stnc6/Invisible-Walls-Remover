This mod adds a keybind that, when pressed, removes all invisible walls from the heist. This only works on host; you'll be able to walk through walls, but other players won't be able to do so without this mod. To restore the walls, you'll need to restart the heist.

INSTALL: Need a SuperBLT. Extract Invisible-Walls-Remover-main and place it in the PAYDAY 2/mods folder.
